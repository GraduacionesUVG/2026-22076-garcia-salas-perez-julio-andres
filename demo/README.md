# Video demostrativo

`demo.mp4` es una demo de 3 minutos y 24 segundos, 1920 × 1080, H.264 a 24 fps. No tiene audio ni narración, por instrucción del autor. Los subtítulos en español están incorporados visualmente y también se incluyen como pista seleccionable y como `subtitulos.srt`.

El video se montó con las 15 capturas originales de operaciones reales ejecutadas en Bruno, más una introducción y un cierre. Cada escena de evidencia permanece 12 segundos para permitir leer la petición y su respuesta. No es una grabación continua del escritorio. Las capturas originales se conservan en `../capturas/`.

La interfaz que aparece es el cliente externo de API Bruno. No se incorporó una aplicación de frontend al código entregado. Las credenciales del entorno privado de captura no forman parte del repositorio.
