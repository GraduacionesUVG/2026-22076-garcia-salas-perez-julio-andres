# Preparación de entrega de backend

Alcance autorizado: extraer el servidor existente a `src/`, sin páginas ni componentes del cliente; conservar API, servicios, repositorios, validaciones, exportadores y pruebas de servidor. Mantener el repositorio original sin cambios.

1. Seleccionar rutas HTTP y módulos; preparar dependencias, configuración de ejemplo y exclusiones.
2. Instalar y verificar la compilación, tipos y pruebas del backend aislado.
3. Documentar instalación, API y base de datos, con límites comprobados.
4. Ejecutar un recorrido real de la API con cuentas QA y datos sintéticos, capturar al menos diez operaciones, borrar exclusivamente los recursos de la demo.
5. Grabar una demo de 3–5 minutos, sin narración, con subtítulos en español, y verificar formato, duración y tamaño.
6. Revisar secretos, ausencia de frontend y limpieza de procesos. Preparar cambios en el fork de Hayser8.

Pendientes del estudiante: informe final aprobado y consentimiento firmado. El PR de entrega final debe esperar a ambos documentos; no marcar el checklist al 100 %.
